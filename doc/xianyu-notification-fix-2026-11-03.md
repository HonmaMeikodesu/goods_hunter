## 图片缺失原因与修复

真实搜索响应的 `exContent.picUrl` 使用 `http://img.alicdn.com/...`。原解析器只接受 HTTPS，将有效图片地址置空；上线前数据库两条闲鱼任务共 68 条记录的图片字段均为空，邮件模板因此没有输出图片标签。

现在将阿里图片 CDN 的 HTTP 地址规范化为 HTTPS，也接受 `//` 开头的图片地址。没有放宽其他 HTTP 来源。真实图片的 HTTPS 请求返回 200，浏览器成功解码。后续扫描会补齐已有记录的缺失图片，不重置去重及通知标记。

已用本次真实搜索结果为两条任务各补齐 30 条旧记录的图片，并在事务中核对通知状态不变。未在本次修复中发送测试邮件或重发旧通知。已发出的邮件内容不能原地更新，修复适用于后续通知。
