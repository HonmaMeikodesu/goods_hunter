# 闲鱼谷子监控接入调研

调研日期：2026-10-26（Asia/Shanghai）。范围：核实官方网页版、开放接口、登录与自动访问规则，为现有阿里云 FC Chrome/Playwright → goods_hunter 调度、MySQL 去重和邮件通知链路评估可行性。依据为官方公开文档、少量未登录页面观察及两个仓库的现有源码；本文区分官方说明、本次观察和工程建议。

## 初步结论

**闲鱼有官方网页版，问题不在“只有 App”，而在官方接入渠道和访问许可。** 官方首页是 [goofish.com](https://www.goofish.com/)，官方《用户服务协议》1.2 也将网站、移动客户端和小程序列为服务形态。[官方用户服务协议](https://terms.alicdn.com/legal-agreement/terms/suit_bu1_other/suit_bu1_other201708081618_51146.html)

**目前未找到向普通个人开发者公开的“全站买家商品关键词搜索 API”。** 可确认的闲鱼开放文档针对受邀小程序及合作方，已列出的常规服务端能力主要是订单、物流、退款和用户信息；不能把“开放平台存在”理解为已经开放全站搜货。这个结论是本次公开资料的检索结果，不排除另行签约、授权的合作能力存在。[小程序快速接入](https://open.goofish.com/doc/quick-start.html)、[合作方服务端文档](https://open.goofish.com/doc/development/dev/server.html)

**现有 FC 可以作为浏览器执行环境，但本次没有验证出成功的关键词搜索，更未验证长期监控。** 本次未登录搜索“未闻花名”显示登录及滑块验证；实际搜索请求的业务返回为错误，不能把页面上的空结果或“猜你喜欢”当成有效关键词结果。具体观察和 FC 影响见第 5、6 节。

**未经闲鱼明确书面许可，不宜把现有 FC 抓取流程直接复制为闲鱼定时任务。** 现行官方《法律声明》2026-09-30 更新、2026-10-07 生效；“访问规则”明确要求第三方智能体或自动化程序取得事先、明确的书面许可并完成必要安全、合规评估，范围明确包含商品信息的搜索、浏览、获取。该限制针对访问方式，不能靠换成网页或降低频率消除。[官方法律声明](https://terms.alicdn.com/legal-agreement/terms/suit_bu1_taobao/suit_bu1_taobao202103061039_91765.html)

## 1. 开放平台与买家搜货的区别

| 官方资料 | 已确认 | 对谷子猎手的意义 |
| --- | --- | --- |
| [小程序快速接入](https://open.goofish.com/doc/quick-start.html) | 小程序运行在闲鱼 App 内；目前只面向运营定向邀请的服务商，不对外公开申请；需企业账号、审批及按需申请权限 | 不是个人注册后即可调用的买家搜索 API |
| [合作方服务端接入](https://open.goofish.com/doc/development/dev/server.html) | API 汇总列出订单创建/查询、发货、退款、物流公司及用户信息；还提供订单状态消息 | 订单查询与订单通知不等于全站商品查询或关键词上新通知 |
| [淘宝官方 API 文档：订单查询](https://open.taobao.com/api.htm?docId=50672&docType=2)、[订单创建](https://open.taobao.com/api.htm?docId=67467&docType=2) | 以上链接由闲鱼官方服务端文档直接指向，接口名分别为 `alibaba.idle.isv.order.query`、`alibaba.idle.isv.goosefish.order.create` | 接口属于交易合作流程，不能凭“查询”二字推断可搜全站商品 |
| [淘宝开放平台](https://open.taobao.com/) | 本次匿名 HTTP 可以拿到文档中心页面壳；web 阅读工具无法打开上述 API 正文，未完成登录后的完整目录枚举 | 应保留检索边界，不能断言所有受限权限中绝无搜索能力 |

公开资料核查包含 `open.goofish.com/doc/` 的快速接入、服务端 API 汇总和权限说明，以及 `open.taobao.com` 的闲鱼/商品查询/搜索相关检索。本次没有查到面向普通个人的全站关键词搜索接口说明、正式搜索参数、配额或申请路径。商家自有商品管理接口即便存在，也需要单独核实数据范围，不能替代买家全站搜货。未将网页内部调用、第三方爬虫服务宣传或非官方仓库视为官方 API 证据。

### 合作接口的认证与部署约束

官方合作方文档要求服务端接入聚石塔，用户 ID、订单信息存储在塔内数据库，服务端部署在塔内；登录授权采用淘宝开放平台 OAuth 流程。文档中提到的卖家 accessToken 180 天有效期，属于特定合作授权流程，**不是 goofish.com 网页登录 Cookie 的有效期**。[合作方服务端文档，第 1、2、3.3 节](https://open.goofish.com/doc/development/dev/server.html)

工程推断：即使将来取得相应合作权限，也需要按实际协议重新评估现有普通 FC + MySQL 部署，不能仅新增一个抓取适配器就宣称符合该合作接入要求。

## 3. 登录、扫码和会话

官方《用户服务协议》3.2 明确：完整服务需要注册并登录，未登录可使用浏览、搜索等基础服务。因此，本次没有找到“所有搜索在官方规则上都必须登录”的硬限制证据；实际 Web 页面仍可能因环境、安全校验或功能差异出现登录提示，二者需要分别记录。3.3 同时规定账户限本人使用，不能以用户愿意提供 Cookie 代替平台许可。[官方用户服务协议](https://terms.alicdn.com/legal-agreement/terms/suit_bu1_other/suit_bu1_other201708081618_51146.html)

隐私政策说明部分功能依赖 Cookie；本次未找到官方对 Web 会话寿命、FC 环境复用、登录自动刷新或无人值守保持登录的承诺。官方快速接入里的 App 扫码绑定是企业小程序绑定流程，不能据此推断普通网页只能扫码登录。[官方隐私政策“二（九）2”](https://terms.goofish.com/legal-agreement/terms/suit_bu1_taobao/suit_bu1_taobao202103021554_43790.html)、[小程序快速接入“3.1”](https://open.goofish.com/doc/quick-start.html)

## 4. robots 与自动访问规则

```text
User-agent: *
Disallow: /find-account
```

该文件未列出 `/search`，但这不构成自动采集许可。应同时适用现行《法律声明》的“信息管理”和“访问规则”：未经许可自动化获取内容受到限制，搜索与浏览也在明确列举范围内；不得隐匿或伪装身份、授权状态，不得绕过验证码或其他安全校验。[官方法律声明](https://terms.alicdn.com/legal-agreement/terms/suit_bu1_taobao/suit_bu1_taobao202103061039_91765.html)

## 6. 现有 FC 架构影响

源码核对表明，可以复用浏览器基础设施和主服务的任务链路，但闲鱼的数据获取与会话管理仍需单独验证。

| 现有能力 | 可以复用的部分 | 闲鱼需要补充验证/设计的部分 |
| --- | --- | --- |
| [FC 调用客户端](../src/api/alicloud/index.ts) | goods_hunter 调用独立 FC，传递参数并接收结构化结果 | 未来独立闲鱼请求/响应类型，区分成功、需要登录、安全校验、上游失败，不能只看 HTTP 200 |
| [通用 FC 浏览器](../../bypass-cloudflare/bypass_cloudflare.py#L723) | 已有 Chrome/Playwright；每次新建隔离 context，可显式注入 Cookie | 每次结束关闭 context，不会自然保留上一请求的 Cookie/localStorage；若需要会话，应另行设计获准的会话保存、恢复与失效处理，尚未证明单靠 Cookie 足够 |
| [Yahoo!フリマ 专用采集器](../../bypass-cloudflare/yahoo_fleamarket.py#L151) | 独立站点采集器、结构化返回与资源清理的组织方式 | Yahoo 目前解析 `__NEXT_DATA__`；本次没有验证闲鱼存在同等的搜索结果结构，不能直接复用其解析器 |
| [商品任务服务](../src/service/hunterArsenal/yahooFleamarket.ts) | 定时执行、首次基线、按商品 ID 去重及后续邮件提醒的模式 | 只在有效搜索成功后推进基线；校验/登录失败时保留原基线并暂停或退避，避免误判和通知风暴 |

以上为本地源码事实与工程建议，不代表闲鱼已适配。FC 生产出口、可接受频率、会话有效期、分页、新发布排序和在售过滤均未验证。若会话不可可靠恢复，届时再比较持久浏览器执行节点与 FC 的职责，不应先假定必须做手机 App 自动化或必须放弃现有 FC。

## 7. 尚待补充的验证及决策边界

以下均未在本次官方资料调研中证实：普通 FC 出口能否稳定加载搜索结果；匿名浏览能否持续翻页；新发布排序的覆盖率；在售/售罄字段；网页会话有效期；可接受轮询频率。没有进行压力测试或取得任何持续自动访问授权。

建议先确认可申请的搜索数据/自动访问权限，再做小范围验证。若取得相应授权，可以“面码”“未闻花名”为样本，依次验证有效搜索结果、切换新发布和翻页、会话失效后的恢复、以及 FC 实际环境的连续运行；先记录运行状态，再接入正式通知。此处建议使用中文关键词做闲鱼样本，搜索命中质量尚未核实，不应直接照搬日站的日文关键词并承诺覆盖率。

这些验证通过后再注册定时任务。本轮没有修改业务代码、调用生产 FC、部署或注册闲鱼任务。
