# 部署历史脚本归档

这里保存 2026-10-23 至 2026-11-03 功能开发实际使用过的部署、检查、恢复和诊断脚本。`manifest.json` 记录每个原始位置、仓库路径和 SHA-256；相同内容的多个副本只保存一份。

这些是历史记录，不是可重复执行的安装器。其中包含生产绝对路径、当时的进程管理方式、任务 ID 和旧配置假设；部分脚本会重启应用、创建 FC 或注册数据库任务。不要直接运行归档脚本。后续部署应基于当前 Git 提交准备变更并重新验证。

- `server/`：服务器私有部署目录里的实际脚本，包括后来的每日刷新调整。
- `local/`：本地准备或诊断阶段的不同版本；与服务器版本完全相同的内容由 manifest 指向服务器副本。包括闲鱼匿名浏览器验证、FC 发布、邮件图片修复和夜间调用统计脚本。
- 当前日常重新登录入口：`../../tools/yahoo-session/login-x11.sh`。
- 当前部署的 systemd 单元：`../production/systemd/`。
- 业务代码分别位于本仓库和同级 `bypass-cloudflare` 仓库。FC 构建入口和参数见 `../../doc/yahoo-fleamarket-setup.md`、`../../doc/xianyu-setup.md`。

归档只包含代码。被这些脚本读取的私有配置、运行环境、浏览器 profile、Cookie、数据库导出和回滚数据不在仓库中；服务器仍保留受权限保护的运行数据与回滚资料。依赖包及编译产物由各自的依赖声明和源码管理。
